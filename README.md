# 100+ проектов, в которых силён Opus 5.5

Коллекция из 121 интерактивного проекта, собранного Claude Opus 5.5 за один автономный запуск 23 сентября 2026 года:

- **100 основных проектов** — десять категорий по десять;
- **10 мультфильмов**;
- **11 игр с живой нейросетью DeepSeek**. Среди них флагман по масштабу — «Город» на 10 000 жителей.

Номера папок перемешаны нарочно: категории и «крутые» проекты не идут подряд, каждая следующая папка — сюрприз. Категорию проекта видно в галерее (фильтры сверху) и в его `meta.json`.

Откройте `index.html` в корне: это галерея со всеми проектами, поиском и тремя режимами просмотра. Цифра «121» наверху сложена из миниатюр всех проектов, фильтры подсвечивают в ней выбранную категорию — наведите на точку.

## Как открыть

- **Любой проект** открывается двойным кликом по `NNN-название/index.html`. Сервер и сборка не нужны.
- **Шрифты и three.js** грузятся из интернета (Google Fonts, jsDelivr). Без сети проекты на three.js показывают понятное сообщение, остальные работают с системными шрифтами.
- **Живые данные** нужны двум проектам: 115 (ветер, Open-Meteo) и 050 (землетрясения, USGS). Без сети у обоих включается иллюстративный режим.
- **Лучший браузер** — свежий Chrome или Safari. WebGL-проекты рассчитаны на видеокарту MacBook. Все 42 проверены на MacBook Air M4, картинка корректная. Частоту кадров мерили только у «Города»: 60 кадров в секунду при DPR 2.

## Игры с нейросетью

Работают через OpenRouter, везде модель `deepseek/deepseek-v4.1-flash` — это решение Станислава: Flash быстрее и дешевле Pro. Общий клиент — `_ai/ai.js`. В нём рассуждение модели для реплик выключено; если ответ обрезался, клиент сам переспрашивает, а JSON, оборванный на середине, спасает.

- **Свой ключ (BYOK).** У коллекции нет встроенного ключа. Каждый игрок подключает свой: кнопкой «Войти через OpenRouter» — это работает на сайте по https, OpenRouter сам выпустит ключ в аккаунте игрока, — или вставив готовый ключ `sk-or-…`. Подключить или отключить ключ для всех игр сразу можно кнопкой «Нейросеть» в шапке галереи. Ключ хранится только в localStorage браузера и уходит напрямую в OpenRouter. Без ключа игры работают в демо-режиме на заготовленных ответах.
- **Стоимость:** партия стоит центы. Проверочные сессии агентов обошлись в $0,006–0,013 каждая.

## Структура

| Путь | Что там |
|---|---|
| `001-…` — `121-…` | все проекты вперемешку. Основная сотня: шейдеры, физика, математика, системы с нуля, игры, звук, объяснялки, слово, данные, объекты. Десять мультфильмов, у каждого своя техника: перекладка, «резиновая» анимация, пластилин, театр теней, пиксель-арт, воксели, палех, типографика, живопись на стекле, музыкальный. Одиннадцать игр, где персонажей играет DeepSeek |
| `IDEAS.md` | все идеи с описанием и исследование, в чём силён Opus 5.5 (с источниками) |
| `BRIEF.md` | правила, по которым работали агенты-сборщики |
| `_ai/` | общий клиент нейросети (BYOK, вход через OpenRouter) |
| `_gallery/` | миниатюры для галереи |
| `_tools/` | инструменты сборки: скриншоты, проверка, галерея. Для просмотра не нужны |

У каждого проекта свой `README.md`: как запустить, что делать, что внутри, что упрощено.

## Как это собиралось

1. **Исследование.** Модель изучила обзоры и бенчмарки Opus 5.5, потом написала 100 идей и правила сборки.
2. **Сборка основной сотни.** Двадцать агентов параллельно собирали по пять проектов: каждый снимал свои проекты в headless-браузере, смотрел на скриншоты и исправлял. Дважды упирались в лимит сессии — после каждого раза оставшееся доделывали новые агенты.
3. **Мультфильмы и игры с нейросетью** добавлены по подсказкам Станислава. Анимацию, как выяснилось, в обзорах Opus 5.5 хвалят особенно.
4. **Финальная проверка.** Все 121 проект прогнаны на десктопе (1440×900) и телефоне (390×844): ошибок в консоли нет, горизонтальной прокрутки нет.
5. **Проверка на настоящем железе.** Все 42 проекта с WebGL дополнительно прогнаны на MacBook Air M4 (Chrome, Metal). Все рисуются так же, как на сервере, ошибок в консоли нет. Именно так нашёлся баг в 015 (занавеска): там отсутствовала загрузка буфера текстурных координат, и на Metal ткань не рисовалась совсем. Серверный программный рендер эту ошибку прощал.
